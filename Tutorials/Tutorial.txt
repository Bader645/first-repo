IMPORTANT NOTE:

if your passkey is in a directory different than the default, ALWAYS use:
git -c core.sshCommand="ssh -i <sshKeyDirectory>"

Order:
working directory --> staging area --> local repo --> remote repo

commands:

git status to view what you have committed and what not, in short views what's happening.

from working directory to staging area: git add

from staging area to local repo: git commit

from local repo to working directory: git checkout / git merge (idk the difference tho)

from local repo to remote repo: git push

from remote repo to local repo: git fetch

generating a keypass (GitHu Public Key):

ssh-keygen -t rsa -b 4096 -C "example@gmail.com"
you can change the directory of where the ssh key sits (like D:\Training-Folder\.ssh\id_rsa)
Then Enter The passphrase
use: type <FileDirectory> to see what's inside (type is the linux counterpart for cat)
copy the content of the file (id_rsa.pub file) and insert it in your Github account.
authenticate in Git command with: ssh -T git@github.com
if you have the key in a directory different than the default, use:
ssh -i <FileDirectory> -T git@github.com
this one forces it to open the key without changing anything
enter your passphrase
you're succesfully authenticated

git -c core.sshCommand="ssh -i D:/Training-Folder/SSH-Keys/id_rsa" push -u origin main
